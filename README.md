# AI Workshop Resources

Welcome to the AI Workshop Resources repository! This repository contains all the prompts and materials you need to build your own specialized, multimodal AI chatbot using Google's Gemini 2.5 Flash Lite, FastAPI, and vanilla JavaScript.

## 🚀 What You Will Build
A fully functional, intelligent chatbot that:
- Specializes in a specific domain (e.g., Cryptography, Healthcare, Movies, etc.).
- Features a beautiful UI generated with Google Stitch.
- Handles text-based Q&A with proper Markdown rendering.
- Includes a multimodal **Vision** feature to analyze uploaded images and verify if they match the chatbot's specialized topic.

## 🛠️ How to Use This Repository

All the instructions and prompts you need are structured into 5 clear stages. Open the [`Workshop_Prompts.md`](Workshop_Prompts.md) file to get started.

Follow along with these steps in the workshop:

1. **Stage 1: Domain Knowledge Brief** - Define your bot's personality, edge cases, and expertise.
2. **Stage 2: Google Stitch UI Generation** - Generate a beautiful, responsive UI.
3. **Stage 3: Architecture Documentation & Build Prompt** - Use Antigravity to generate the backend, frontend logic, and project plan.
4. **Stage 4: Add Vision Feature (Antigravity)** - Wire up the image upload and vision analysis endpoint.
5. **Stage 5: GitHub Guide & Deployment** - Save your project, initialize Git, and push to your own repository.

## 📋 Prerequisites
- A Google Gemini API Key (get one at [ai.google.dev](https://ai.google.dev/))
- Python installed on your local machine
- A GitHub account for deployment
